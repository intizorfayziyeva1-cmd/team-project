## 📖 Loyiha haqida

**MyTube** — HTML, CSS va JavaScript yordamida yaratilgan, YouTube'dan ilhomlangan veb-sayt. Loyiha jamoaviy ishlash jarayonida yaratilgan bo'lib, video kartalar to'plami, tezkor qidiruv va barcha qurilmalarga moslashuvchi dizaynni o'z ichiga oladi.

Sayt hech qanday framework yoki tashqi kutubxonasiz, toza (vanilla) texnologiyalarda yozilgan, shuning uchun yengil va tez ishlaydi.

## ✨ Imkoniyatlari

- 🔍 **Jonli qidiruv** — matn yozilishi bilan videolar sarlavha bo'yicha real vaqtda filtrlanadi
- 🎬 **Video kartalar** — rasm, sarlavha va kanal nomi bilan chiroyli kartochkalar
- 📱 **Responsiv dizayn** — kompyuter, planshet va telefonlarga moslashadi
- ✨ **Hover effektlari** — kartalar ustiga kursor olib borilganda silliq animatsiya
- 🧭 **Navigatsiya menyusi** — Bosh sahifa, Shorts, Musiqa, O'yinlar bo'limlari
- 🌐 **O'zbek tilidagi interfeys**

## 🛠 Texnologiyalar

| Texnologiya | Vazifasi |
|-------------|----------|
| **HTML5** | Sahifa tuzilmasi va semantik teglar |
| **CSS3** | Dizayn, Flexbox, Grid, animatsiyalar, media queries |
| **JavaScript (ES6)** | Qidiruv va kartalarni filtrlash mantig'i |

## 🚀 Ishga tushirish

Loyihani kompyuteringizda ishga tushirish uchun hech narsa o'rnatish shart emas.

**1. Repository'ni klonlang:**

```bash
git clone https://github.com/intizorfayziyeva1-cmd/team-project.git
```

**2. Loyiha papkasiga kiring:**

```bash
cd team-project
```

**3. `index.html` faylini brauzerda oching:**

- Faylni ikki marta bosib oching, yoki
- VS Code'da **Live Server** kengaytmasi orqali ishga tushiring

## 📱 Responsiv dizayn

Sayt ekran o'lchamiga qarab avtomatik moslashadi:

| Qurilma | Ekran kengligi | Kartalar joylashuvi |
|---------|----------------|---------------------|
| 🖥 Kompyuter | 768px dan katta | 3 ustun |
| 📱 Planshet | 768px gacha | 2 ustun |
| 📱 Telefon | 450px gacha | 1 ustun |

## 🎨 Dizayn

- **Asosiy rang:** qizil (`red`) — logotip, hover va fokus holatlari uchun
- **Fon:** `#f5f5f5` — och kulrang
- **Kartalar:** oq fon, yumaloq burchaklar va yengil soya
- **Shrift:** Arial, sans-serif
